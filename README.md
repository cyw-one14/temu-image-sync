# TEMU 商品图同步助手 0.1.0

确认商品轮播图后，自动打开详情装修，按相同顺序逐张插入已上传的素材，并保存详情装修到当前编辑表单。

## 适配范围

- 地址：`https://agentseller.temu.com/goods/edit?productDraftId=...`。
- 单个颜色规格、英语素材，使用页面底部的“详情图文 → 开始装修”编辑器。
- 只同步商品规格中的轮播图，不处理视频、标题、价格、属性或多规格图片。
- 复用 TEMU 素材中心里的已上传图片，插件自身不上传本地文件、不处理图片尺寸、不调用外部 AI 服务。
- 只保存详情装修到当前表单，不点击“保存草稿”“创建”或“发布”。草稿持久保存和最终发布由用户操作。

## 在 Edge 中加载

1. 打开 Edge 的扩展管理页（地址栏输入 `edge://extensions`）。
2. 开启开发人员模式，选择“加载解压缩的扩展”。
3. 选择本项目的 `extension` 文件夹，即 `D:\00 Work\temu-image-sync\extension`，不要选择项目根目录或 ZIP 文件。
4. 新开一份测试商品草稿进入编辑页，右上角应出现“商品图同步助手”。
5. 在轮播图素材中心完成选图并点击“确认”。关闭选图窗口后，插件会等待片刻再逐张同步详情。
6. 看到“已同步 N 张 · 图片与顺序一致”后，手动检查底部详情预览。测试过程中请保持该页面，插件工作时若手动点击或输入会暂停自动操作。

该插件仅申请本地设置存储，以及在 `agentseller.temu.com/goods/*` 下运行的权限。没有全站访问、Cookie、调试器、下载或本地文件访问权限。ChatGPT 浏览器工具为本轮手动上传需要的“允许访问文件 URL”与本插件无关。

## 操作和限制

- “自动同步”可关闭，关闭后仍可点击“立即同步”。
- 素材中心或其他窗口尚未关闭时，会等待；同步失败后可检查页面并点击“重新检查”。
- 图片和当前详情完全一致时跳过，避免重复插入。
- 新草稿的空白详情可以自动填充。现有手动详情会受到保护，插件不会直接覆盖。
- 插件自己生成且未被手动改动的纯图片详情可以随商品图更新；如果 TEMU 弹出额外的清空确认，插件会停止，需要人工处理后重试。
- 素材不在当前列表时，会尝试用先前记录的素材名称搜索；安装前已存在的旧图片可能没有名称记录，需要重新从商品图素材中心确认选图后再同步。
- 图片顺序、素材名称和最后一次写入的详情指纹保存在浏览器扩展的本地存储，按商品草稿区分；超过七天的记录不再用于自动覆盖判断。不会将这些记录发送到项目服务器。
- 刷新或关闭页面前，请按日常流程处理尚未保存的编辑内容；详情装修保存完成不代表商品草稿已持久保存。
- TEMU 页面结构更新后可能需要调整适配代码，找不到控件时会报错停止。

## 开发验证

运行环境：Node.js 24。扩展运行不需要 npm 安装；以下依赖仅用于开发测试。

```powershell
npm ci --ignore-scripts
npm test
npm run check
```

`extension/` 是可加载的完整扩展目录；`tests/` 使用 jsdom 模拟已检查的 TEMU 页面交互。`artifacts/` 是本地测试证据，不包含在插件 ZIP 中，也不会进入 Git 提交。
