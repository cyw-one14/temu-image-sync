# TEMU 商品图同步助手 0.2.1

确认商品图后，自动把各颜色的英语轮播图按页面顺序合并、去重，填入英语详情图文。

## 功能

- 支持多个颜色规格：按颜色行顺序、每行图片顺序合并，相同图片只保留第一次出现的位置。
- 商品图增加、删除、排序或颜色行变化后，自动更新扩展自己生成且未被手动改动的详情。
- 图片已一致时跳过；所有英语商品图为空时保留现有详情；拖动排序期间等待。
- 支持在其他语言详情标签下触发：临时切换到英语，完成后恢复原语言标签。
- 保留其他语言“使用英语图片素材”或“不使用任何详情图文素材”的设置。
- 保护已有手动详情、文本组件和被手动修改过的图片详情。
- 提供自动同步开关、立即同步、重新检查、颜色数、素材语种数和当前语言状态。
- 只保存详情装修到当前表单，整份草稿保存和商品发布由用户操作。

## 多语言的实际行为

当前检查的 TEMU 页面中，英语详情有装修编辑器；西班牙语详情只有“使用英语图片素材”或“不使用任何详情图文素材”，没有独立装修入口。

因此，扩展把各颜色的英语商品图同步到英语详情，其他语言按后台设置继承或保持不使用。其他语言的轮播图不会混入英语详情。本版不提供后台没有的独立多语言详情装修，也不做图片翻译。

AI 识图、标题生成及商品属性自动填写不在本版范围，不需要 AI 服务或 API 密钥。

## Edge 安装与更新

1. 在地址栏打开 `edge://extensions`。
2. 首次安装：开启开发人员模式，选择“加载解压缩的扩展”，选择 `D:\00 Work\temu-image-sync\extension`。
3. 更新：点击此扩展卡片的重新加载图标，确认版本为 0.2.1。
4. 新开一份测试草稿编辑页，让新脚本注入。刷新旧页面前先处理未保存的编辑内容。
5. 在各颜色的英语商品图区上传或选择图片，并确认。插件等待素材窗口关闭后同步。
6. 同步期间暂不点击或输入；完成后检查页面底部的详情预览，再自行保存整份商品草稿。

扩展仅申请 `storage` 权限，内容脚本只匹配 `https://agentseller.temu.com/goods/*`。没有外部 AI 服务、全站访问、Cookie、调试器、下载或本地文件权限。

## 数据与限制

- 复用 TEMU 素材中心中已上传的图片，不重复上传本地文件，不调整尺寸。
- 适配地址为 `https://agentseller.temu.com/goods/edit?productDraftId=...`。未知页面结构或确认提示会停止同步。
- 旧素材可能没有名称记录，需要从商品图素材中心重新确认，让扩展记录名称以便搜索。
- 素材名称、图片顺序和最后写入的详情指纹，按草稿保存在扩展本地存储；七天前的记录不用于自动覆盖判断，不发往项目服务器。
- 平台限制、不可用素材和网络问题可能中断同步，扩展会报告错误并保留原详情预览。
- 装修保存不等于整份草稿已持久保存，关闭或刷新前仍需按日常流程处理草稿。

## 开发

使用 Node.js 24；运行扩展不需要安装 npm 依赖，依赖只用于开发测试。

```powershell
npm ci --ignore-scripts
npm test
npm run check
```

`extension/` 是完整扩展目录，`tests/` 为 jsdom 测试，`artifacts/` 为不提交的本地测试证据。
